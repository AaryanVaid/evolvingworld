What is EvolvingWorld? (will be finished at 2.0)

A Minecraft plugin where the world evolves over phases.
Players progress individually while the world progresses globally.

Features
- Player phases
- World phases
- Restrictions based on phase
- Dynamic world difficulty
- Abilities, Hotbar locked, usable on demand
- Vfx,Sfx and a way to obtain abilities, also a rolling system with rarities.
- Durability cooldown with every ability being unique and useful in their own way. (Max 3, last 3 hotbars reserved, if filled, will be discarded, be prepared)
